# AutoEmailBasic ✉️

Ein einfaches Python-Kommandozeilen-Tool zur automatischen Generierung von strukturierten E-Mail-Texten für Bewerbungen.

## 📌 Funktionen
* **Dynamische Anrede:** Passt die Anrede und Grammatik automatisch an das Geschlecht der Zielperson an (`Frau` / `Herrn`).
* **Kommandozeilen-Eingabe:** Fragt Daten wie Absender, Empfänger und Geschlecht direkt über die Konsole ab.
* **Standardisierter Bewerbungstext:** Generiert einen sauberen Textbaustein für E-Mail-Bewerbungen inkl. Anhang-Hinweis.

## 🚀 Nutzung / Start
1. Stellen Sie sicher, dass Python 3.x installiert ist.
2. Starten Sie das Skript über die Konsole oder PyCharm:
   ```bash
   Auto-Email.py
